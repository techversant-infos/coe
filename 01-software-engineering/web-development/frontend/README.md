# Frontend Engineering

Frontend engineers should complete the React foundation before moving into framework-specific delivery.

## Paths

| Path | Use when |
|---|---|
| [React](./react/intermediate.md) | You need the UI library foundation: components, state, effects, forms, testing |
| [Next.js](./nextjs/intermediate.md) | You are building modern frontend apps against Laravel APIs using the App Router |

## Recommended Order

1. [React](./react/intermediate.md)
2. [Next.js](./nextjs/intermediate.md)
3. Project-specific component library and product onboarding
