# 03. Platform Engineering

Platform Engineering is a planned academy discipline for engineers who own delivery infrastructure, cloud platforms, deployment safety, observability, and incident response.

This section is not a replacement for project-specific runbooks. It should teach the shared platform mindset and then link to stack/provider-specific implementation paths.

## Intended Scope

- DevOps fundamentals
- Cloud foundations
- CI/CD design
- Build and artifact management
- Environment strategy
- Kubernetes basics
- Containers and image security
- Observability
- Infrastructure as Code
- Secrets and configuration management
- Release engineering
- Incident response
- Cost awareness and capacity planning

## Recommended Future Order

1. DevOps and delivery fundamentals
2. CI/CD and release safety
3. Containers and deployment packaging
4. Cloud foundations
5. Infrastructure as Code
6. Observability and incident response
7. Kubernetes and platform operations
8. Cost, reliability, and governance
