# 01. Engineering Foundations

**Status:** Draft · **Owner:** CoE Team · **Last updated:** 2026-11-05 · **Next review:** 2027-02-05

This stage is the academy's [Engineering Foundations](../00-engineering-foundations/README.md) course (academy
discipline 00), the shared baseline for every Techversant engineer. If you have already completed it, show the evidence in the project below and
move on. Back to the [roadmap](./README.md).

## Git Workflow

The branching, commit, pull request and release model. On a client project, the pull request is also how the client's
team learns what you changed and why.

**What to learn:** branch naming, Conventional Commits, pull requests with test evidence, promotion and rollback.

**Resources:** [Git Workflow](../00-engineering-foundations/01-git-workflow.md)

**Level:** Foundation · Core

## AI Usage

Safe use of AI coding assistants such as Claude Code, Cursor and Copilot: when AI use is safe, when it needs
collaboration and when it is forbidden.

**What to learn:** the delegation rule of thumb and the evidence you need before committing AI-assisted work.

**Resources:** [AI Usage](../00-engineering-foundations/02-ai-usage.md)

**Level:** Foundation · Core

## Secure Engineering

The security basics for anyone who touches authentication, access control, secrets, personal data, payments, APIs or
production data.

**What to learn:** spotting common security risks before a reviewer does.

**Resources:** [Secure Engineering](../00-engineering-foundations/03-secure-engineering.md)

**Level:** Foundation · Core

## Communication

Clear pull request descriptions, status updates, bug reports and handover notes (the Handoff Note template). FDEs write for the client as well as
for colleagues.

**What to learn:** the PR summary, blocker update and handoff note templates.

**Resources:** [Communication](../00-engineering-foundations/04-communication.md)

**Level:** Foundation · Core

## Developer Excellence

The core engineering discipline: clean code, design principles, testing, review and ownership.

**What to learn:** the Developer Excellence curriculum and its review checklist.

**Resources:** [Developer Excellence Curriculum](../00-engineering-foundations/05-dev-excellence/01-curriculum.md)

**Level:** Foundation · Core

## Project: Show Your Foundations Evidence

**Brief:** Collect the [Foundations completion evidence](../00-engineering-foundations/README.md#completion-evidence)
from your real work and walk your lead through it.

**Size:** 1–2 hours to collect, if you have completed the course

**Verification**, checked by your lead:

- [ ] A merged pull request of yours that follows the Git Workflow
- [ ] You place five tasks your lead gives you at the right delegation level from
  [section 2.1 of the AI Era Coding Guidelines](../../standards/general/ai-era-coding-guidelines.md#21-delegation-levels),
  including at least one Red Zone task
- [ ] In a pull request your lead picks, you list the security risks and match them to the
  [Security Audit Checklist](../../security/audit/security-audit-checklist.md)
- [ ] A review you wrote on a colleague's pull request using the Developer Excellence review checklist
- [ ] A pull request description and a handover note written with the Communication templates, and a bug report
  with steps to reproduce, the expected result and the actual result
