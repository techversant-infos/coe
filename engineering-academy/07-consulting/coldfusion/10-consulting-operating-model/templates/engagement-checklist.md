# Engagement Checklist

> Pre-engagement, during, and post-engagement checklist for CF consulting projects.

---

## Pre-Engagement

### Qualification

- [ ] Initial inquiry received
- [ ] Client type confirmed (ColdFusion)
- [ ] Decision-maker identified
- [ ] Budget range confirmed ($15K minimum)
- [ ] Timeline established
- [ ] Go/No-Go decision made

### Contracting

- [ ] SOW drafted
- [ ] Rates confirmed
- [ ] NDA signed
- [ ] Contract signed
- [ ] Insurance confirmed
- [ ] Team capacity allocated

### Preparation

- [ ] Client background research complete
- [ ] Discovery questions prepared
- [ ] Materials packed (laptop, demos, examples)
- [ ] Travel/logistics arranged (if applicable)

---

## During Engagement

### Discovery

- [ ] Discovery workshop scheduled
- [ ] Attendees confirmed
- [ ] Workshop facilitated
- [ ] Notes captured
- [ ] Follow-up items tracked
- [ ] Next steps agreed

### Assessment

- [ ] Code access granted
- [ ] Environment access granted
- [ ] Stakeholder interviews completed
- [ ] Technical deep-dive scheduled
- [ ] Assessment in progress
- [ ] Findings documented

### Proposal

- [ ] Scope defined
- [ ] Estimate developed
- [ ] Proposal drafted
- [ ] Internal review complete
- [ ] Proposal delivered
- [ ] Follow-up scheduled

---

## Post-Engagement

### Won Engagements

- [ ] Kickoff scheduled
- [ ] Team onboarded
- [ ] Project plan created
- [ ] Communication cadence established

### Lost Engagements

- [ ] Feedback collected (if possible)
- [ ] CRM updated
- [ ] Lessons noted
- [ ] Relationship maintained
