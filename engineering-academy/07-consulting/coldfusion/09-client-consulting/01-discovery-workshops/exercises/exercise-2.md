# Exercise 2: Whiteboard Facilitation

> Practice mapping application architecture on a whiteboard with a client.

---

## Scenario

Client: Pinnacle Regional Health System
Application: BlogCFC5 (substitute their CF application if available)
Goal: Map the current architecture to identify modernization opportunities

---

## Exercise 2A: Architecture Mapping

Using the client's description, create an architecture diagram showing:

- Frontend (UI layer)
- Backend (CF application)
- Database
- External integrations
- Authentication
- Deployment environment

**Format:** Use boxes and arrows. Label each component.

---

## Exercise 2B: Questions to Ask

Before whiteboarding, prepare these questions:

| Question | Why It Matters |
|----------|----------------|
| "Where is the application hosted?" | Identifies infrastructure |
| "How do users authenticate?" | Security and session handling |
| "What databases are in use?" | Migration complexity |
| "Any external integrations?" | Dependencies |
| "What happens when things break?" | Monitoring and support |

---

## Exercise 2C: Document and Present

After the whiteboard session:

1. Take a photo of the diagram
2. Create a digital version
3. Note any questions that arose
4. Identify next steps

---

## Deliverable

- Architecture diagram (hand-drawn or digital)
- List of questions prepared
- Notes on what you learned
