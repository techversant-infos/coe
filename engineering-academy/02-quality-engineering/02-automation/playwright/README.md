# Playwright Automation Learning Paths

> **Objective:** Build automation engineers who can write, maintain, and improve Playwright automation with good test design.
> **Status:** Draft for pilot batch review - v0.2.

---

## Choose Your Track

| Track | Audience | Goal |
|---|---|---|
| [Manual Tester to Automation Engineer](./01-manual-to-automation.md) | Manual testers with little or no programming experience | Become productive writing and maintaining Playwright UI/API tests |
| [Automation Engineer to Senior Automation Engineer](./02-senior-automation.md) | Automation engineers with 6+ months of automation experience | Own automation strategy, framework quality, CI, reporting, and mentoring |

---

## Recommended Entry Points

Start with **Manual Tester to Automation Engineer** if you:

- execute manual test cases today,
- know what good testing looks like,
- have little or no programming experience,
- have never owned an automation PR.

Start with **Automation Engineer to Senior Automation Engineer** if you:

- already write automated tests,
- understand locators and assertions,
- can debug a failing Playwright test,
- want to own framework design and automation strategy.
