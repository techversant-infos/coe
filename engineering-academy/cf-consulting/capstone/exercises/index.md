## Prerequisites

1. **Clone or download BlogCFC5**
   ```bash
   git clone https://github.com/teamcfadvance/BlogCFC5.git
   ```

2. **Set up local environment**
   - Adobe ColdFusion 10+ or Lucee 5+
   - SQL Server 2012+
   - See [../README.md](../README.md) for detailed setup

3. **Enable debugging**
   - ColdFusion Administrator → Debugging & Logging → Enable Request Debugging

---

## Exercise Workflow

### Per Phase

1. **Read the exercise** before the session
2. **Examine the code** in BlogCFC5
3. **Complete the worksheet** with your findings
4. **Create the deliverable** as specified
5. **Present to peer** for feedback

### Capstone Deliverable

By completing all exercises, you produce:

```
BlogCFC5-Consulting-Package/
├── 01-request-analysis.md     (Phase 1)
├── 02-assessment-report.md    (Phase 2)
├── 03-modernization-strategy.md (Phase 3)
├── 04-lucee-plan.md            (Phase 4)
├── 05-cloud-architecture.md    (Phase 5)
├── 06-ai-proposal.md           (Phase 6)
├── 07-ui-plan.md               (Phase 7)
├── 08-optimization-report.md   (Phase 8)
├── 09-discovery-notes.md       (Phase 9)
└── final-proposal.md           (Compilation)
```

This package represents a complete consulting engagement deliverable for the BlogCFC5 modernization.

## Tips

- **Start with Phase 2** — the assessment exercise gives context for all others
- **Use debugging** — enable CF request debugging to see query timelines
- **Document everything** — your notes become the deliverable
- **Role-play Phase 9** — practice with a partner
