# Exercise 3: Status Update Writing

> Practice writing clear, professional status updates for clients.

---

## Scenario

You're two weeks into a CF migration project. Write a status update for the client.

---

## Status Update Template

### Header

```
To: [Client Name]
From: [Your Name]
Date: [Date]
Project: [Project Name]
Week: [X] of [Y]
Status: [On Track / At Risk / Off Track]
```

| | | | |

|-------------|-------|-----|
| | | |

### Budget Status

| Category | Budgeted | Spent | Remaining |
|----------|----------|-------|-----------|
| Hours | X | Y | Z |

## Example Status Update

```
To: Pinnacle Regional Health System
From: Techversant Consulting
Date: July 28, 2026
Project: BlogCFC5 Lucee Migration
Week: 2 of 8
Status: On Track
```

**This Week's Progress:**
- Completed compatibility scan of all 120 CFM files
- Identified 3 files with Adobe-specific functions
- Set up development environment

**Decisions Made:**
1. Use CommandBox for local development (agreed with client)

**Issues:**
- SQL Server version is older than planned (no impact)

**Next Week:**
- Complete compatibility fixes for 3 files
- Begin database migration planning
