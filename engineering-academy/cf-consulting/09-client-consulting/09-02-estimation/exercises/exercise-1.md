# Exercise 1: Project Sizing with WBS

> Break down a ColdFusion modernization project into work packages.

---

## Scenario

**Client:** Summit Manufacturing
**Project:** ColdFusion 9 to Lucee Migration
**Scope:** 120 CFM files, 45 database tables, custom authentication

---

## Exercise 1A: Work Breakdown Structure

Create a WBS for the migration project:

```
1.0  PROJECT MANAGEMENT
      1.1  Kickoff
      1.2  Status Updates
      1.3  Closure

2.0  DISCOVERY
      2.1  Environment Audit
      2.2  Code Analysis
      2.3  Dependency Mapping

3.0  PREPARATION
      3.1  Development Environment
      3.2  Testing Framework
      3.3  Migration Script

4.0  MIGRATION
      4.1  Compatibility Fixes
      4.2  Database Migration
      4.3  Authentication
      4.4  Testing

5.0  DEPLOYMENT
      5.1  Staging Deployment
      5.2  User Acceptance Testing
      5.3  Production Deployment
      5.4  Post-launch Support
```

**Your task:** Add hour estimates for each work package.

---

## Exercise 1B: Three-Point Estimation

For the largest work package, provide three estimates:

**Work Package:** 4.1 Compatibility Fixes

| Estimate Type | Hours | Assumption |
|---------------|-------|------------|
| Optimistic (O) | | Everything works first try |
| Likely (M) | | Minor issues found |
| Pessimistic (P) | | Major compatibility problems |

**Expected (PERT):** (O + 4M + P) / 6 = ____________ hours

---

## Deliverable

Complete WBS spreadsheet with:
- Work packages
- Hour estimates
- Dependencies
- Risk flags
