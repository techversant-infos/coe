# Exercise 2: Risk Buffer Calculation

> Learn to add appropriate risk buffers to estimates.

---

## Scenario

You've estimated a CF upgrade project at 160 hours. Now you need to add risk buffers.

## Exercise 2B: Buffer Calculation

**Base Estimate:** 160 hours

**Complexity Adjustment:**
- Code quality (1-5): 3 → +15%
- Team experience (1-5): 2 → +20%
- Documentation (1-5): 1 → +25%

**Complexity Adjustment Total:** ____________%

**Final Estimate:**
```
Base: 160 hours
+ Complexity: 160 × ___% = ___ hours
+ Risk buffer: ___% = ___ hours
= Total: ___ hours
```
