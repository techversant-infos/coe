# Front-End Paths

**Status:** Draft · **Owner:** CoE Team · **Last updated:** 2026-11-06 · **Next review:** 2027-02-06

A front-end developer builds the pages, forms and interactions people use in client applications. Each front-end
path teaches one framework through the same ten stages, and the projects build a complete front end for the
RealWorld blogging app. Back to [Software Engineering](../README.md).

## The Ten Stages

Every front-end path uses these stages, so you can move between frameworks and compare them:

1. HTML, CSS and Accessibility
2. JavaScript and TypeScript
3. Framework Fundamentals
4. State and Data Flow
5. Routing
6. Forms and Validation
7. Working with APIs
8. Rendering and the Meta-Framework
9. Testing
10. Performance and Production

Sign-in and token handling in stages 07 and 08 are Red Zone work: you write that code by hand, and a senior engineer
reviews it.

## The Practice App

Every front-end path builds the same app. See the [practice app](./practice-app.md) page for how to set it up and
run its tests.

## Working with Back-End Paths

Every [back-end path](../01-backend/README.md) builds the RealWorld API that your front end calls. When you complete
one of each, your own front end runs against your own API.
