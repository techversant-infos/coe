## The Ten Stages

Every back-end path uses these stages, so you can move between stacks and compare them:

1. Language Fundamentals
2. The Framework
3. HTTP and REST APIs
4. Databases and Data Access
5. Validation and Error Handling
6. Authentication and Authorization
7. Background Jobs and Caching
8. Testing
9. Security and Performance
10. Deployment and Operations

Stage 06, and production database migrations in stage 10, are Red Zone work: you write that code by hand, and a
senior engineer reviews it.

## The Practice App

Every back-end path builds the same app. See the [practice app](./practice-app.md) page for how to set it up and run

## Working with Front-End Paths

Every back-end path builds the RealWorld API, and every [front-end path](../02-frontend/README.md) builds a front end
for it. When you complete one of each, your own front end runs against your own API.
