# Frontend Engineering

Frontend engineers should complete the React foundation before moving into framework-specific delivery.

## Paths

| Path | Use when |
|---|---|
| [React](./01-react/01-react-learning-path.md) | You need the UI library foundation: components, state, effects, forms, testing |
| [Next.js](./02-nextjs/01-nextjs-learning-path.md) | You are building modern frontend apps against Laravel APIs using the App Router |

## Recommended Order

1. [React](./01-react/01-react-learning-path.md)
2. [Next.js](./02-nextjs/01-nextjs-learning-path.md)
3. Project-specific component library and product onboarding
