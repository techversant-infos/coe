# AI Assisted Testing

This planned path teaches QA and automation engineers how to use AI for test design, test generation, debugging, and review without delegating final test judgment.

## Intended Scope

- Convert manual test cases into Playwright tests
- Generate selector alternatives
- Refactor Page Objects
- Explain failed traces
- Generate API assertions
- Draft accessibility checks
- Review automation PRs

Pair with [Manual Tester to Automation Engineer](../../02-quality-engineering/02-automation/playwright/01-manual-to-automation.md).

## Guardrails

- Human owns test strategy and risk selection.
- AI-generated tests must be reviewed line by line.
- Do not paste secrets, production data, PII, or customer data into AI tools.
- Keep generated tests small, explainable, and traceable to a real risk.
