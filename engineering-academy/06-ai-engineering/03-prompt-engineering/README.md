# Prompt Engineering

This planned path teaches practical prompting for engineering work: explanation, planning, review, test design, documentation, and refactoring support.

## Intended Scope

- Prompt structure: goal, context, constraints, examples, output format
- Asking for assumptions and risk checks
- Prompting for code review and test ideas
- Prompting for documentation drafts
- Prompting for migration plans and rollback thinking
- Evaluating AI output against repository standards

Until this path is written, use the existing [AI Prompt Handbook](../../../ai/prompts/developer_handbook_Full.md).
