# AI Assisted Development

This planned path teaches engineers how to use AI coding assistants without giving up engineering judgment.

## Intended Scope

- Delegation levels and Red Zone work
- AI-assisted explanation and code reading
- Test scaffolding and refactoring support
- AI pre-review before human review
- Prompting with repo context
- Commit disclosure and review notes
- Avoiding hallucinated APIs and insecure shortcuts
