# Assessment Rubric Design

Standards for creating effective assessments that measure learning outcomes accurately and fairly.

## When to Use This Skill

Use this skill when:
- Creating assessments for learning phases
- Designing evaluation rubrics
- Planning quizzes, practicals, or projects
- Defining success criteria for exercises

## Assessment Types

### Formative Assessments
Purpose: Check understanding during learning
- Quick knowledge checks
- Mini-quizzes (5-10 questions)
- Concept mapping
- Self-reflection prompts
- Quick practical tasks

### Summative Assessments
Purpose: Evaluate mastery at phase end
- Practical projects
- Comprehensive quizzes
- Code reviews
- Portfolio submissions

### Capstone Assessments
Purpose: Validate full-path competency
- Multi-phase project
- Real-world scenario application
- Portfolio review
- Practical demonstration

## Rubric Design Principles

### Clear Criteria
Each rubric must have 3-5 specific, measurable criteria.
Example:
- ✅ "Uses locators with appropriate specificity"
- ❌ "Good test structure"

### Measurable Levels
Use consistent scale (typically 3-4 levels):
- **Exemplary**: Exceeds expectations
- **Proficient**: Meets all requirements
- **Developing**: Meets some requirements
- **Beginning**: Meets few requirements

### Balanced Weighting
Weight criteria by importance:
- Core skills: 30-40%
- Supporting skills: 15-20% each
- Process/approach: 10-15%

## Rubric Templates

### Practical Assessment Rubric
```markdown
## Assessment: [Title]

**Type:** Practical / Project / Quiz
**Duration:** XX minutes
**Prerequisites:** [What learner should know]

### Criteria

| Criteria | Exemplary (4) | Proficient (3) | Developing (2) | Beginning (1) |
|----------|---------------|----------------|----------------|---------------|
| **Criterion 1** | Description | Description | Description | Description |
| **Criterion 2** | Description | Description | Description | Description |
| **Criterion 3** | Description | Description | Description | Description |

### Passing Standard
- Minimum score: X out of Y
- Must meet "Proficient" or better on core criteria

### Feedback Guidelines
- Provide specific, actionable feedback
- Highlight strengths and growth areas
- Link to relevant learning resources
```

### Quiz Assessment Rubric
```markdown
## Quiz: [Title]

**Questions:** X
**Duration:** XX minutes
**Format:** Multiple choice / Short answer / Code writing

### Passing Criteria
- Minimum correct: X/Y questions
- Must answer all code questions correctly

### Feedback
- Automated for multiple choice
- Manual review for code answers
- Provide explanations for incorrect answers
```

## Assessment Best Practices

### Clear Instructions
- State exactly what is being assessed
- Provide examples of passing work
- Specify any allowed resources

### Fair Evaluation
- Assess only stated objectives
- Allow reasonable accommodation for skill levels
- Provide multiple attempts when appropriate

### Actionable Feedback
- Tell learners what to improve
- Link to specific lessons/resources
- Be encouraging but honest

### Continuous Improvement
- Track assessment results
- Identify common failure points
- Update content based on results
- Refine rubrics for clarity
