## Rules

- Each file keeps its old repository path under `archive/`, so it is easy to restore.
- Each Markdown file starts with a banner that names the replacement.
- CI link, spelling and lint checks skip this folder.
- To restore a file, move it back with `git mv` and remove the banner.
- To finish a review, delete the file and its row below.
